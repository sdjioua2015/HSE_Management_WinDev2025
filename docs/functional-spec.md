# Documentation fonctionnelle du logiciel HSE

## 1. Objet du logiciel

Le logiciel permet de gérer les activités de sécurité, hygiène et environnement d’une entreprise dans un contexte de production ou de service.

## 2. Module d’authentification

- saisie du login et du mot de passe
- validation des droits
- restriction d’accès selon profil

## 3. Module personnel

- gestion du personnel
- matricule
- site
- département
- poste
- date d’embauche

## 4. Module incidents

- déclaration d’un incident
- type d’incident
- gravité
- site
- date de survenance
- description
- causes probables
- mesures immédiates
- statut

## 5. Module audit

- planification d’un audit
- points contrôlés
- conformité ou non-conformité
- niveau de risque
- observations

## 6. Module actions

- création d’une action corrective
- responsable
- date d’échéance
- priorité
- statut
- rattachement à un incident ou audit

## 7. Module documents

- stockage des procédures et documents techniques
- rattachement à un site
- type de document

## 8. Module reporting

- rapports par site
- rapports par gravité
- liste des actions en retard
- audits non conformes
- tendances par période

## 9. Sécurité

- contrôle d’accès par profil
- journalisation des événements
- validation des formulaires
- respect des droits de suppression
